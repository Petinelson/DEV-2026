# 📘 Material de Apoio - Desenvolvimento de Sistemas

Este material tem como objetivo servir como apoio aos alunos de **Desenvolvimento de Sistemas**.

## Conteúdo abordado
O material contempla:

- **Lógica de Programação em Portugol**
- **Lógica de Programação em Python**
- **Exercícios práticos diversos**

## Como desenvolver as atividades
As atividades podem ser desenvolvidas:

- no **navegador**
- em algum **editor de texto**
- em ambientes como o **VS Code**

## Objetivo
Proporcionar aos alunos uma base prática e teórica para o desenvolvimento do raciocínio lógico e da programação.
